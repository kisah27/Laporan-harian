LAPORAN HARIAN UNIT SINAR MAJU JAYA

THE UNI VENUS SERANG BANTEN

Memuat sinkron…
🧪 Mode review: aplikasi ini sengaja diisi data contoh supaya Anda bisa langsung melihat alurnya. Semua data contoh bisa dihapus lewat tab 📖 Panduan & Setelan → Kosongkan Semua Data, lalu isi master data yang sebenarnya.

Input Laporan Unit

Isi baris berikut lalu klik + Tambah Laporan. Laporan otomatis masuk ke tabel kontrak yang sesuai dengan unit-nya (dilihat di tab 📤 Rekap & Kirim WA).

Ringkasan Tanggal

Jumlah laporan per kontrak untuk tanggal yang sedang dipilih di form.

Rekap & Kirim WhatsApp

Semua kontrak (A–D) digabung dalam satu pesan — dikirim sekali.


      

        
        Pratinjau pesan gaya struk — di WhatsApp: judul & tanggal tebal, isi rata mono bergaris, plus emoji warna status (🟡 Kirim · 🟢 Standby · 🔵 Inap · 🔴 Storing).
      

    

  

  

  

    

      

        
Laporan Bulanan per No. Pol

        
Rekap satu bulan penuh untuk setiap unit — file Excel bergaris berisi jumlah Kirim/Inap/Standby/Storing per unit, kalender status tanggal 1–31, dan detail semua laporan bulan itu.

      

      

        
        
        
      

    

    

    

  






  

    
Master Tujuan

    
Nama tujuan / customer / lokasi di sini akan muncul sebagai dropdown pada form input laporan.

    

      
      
      
    

    

  






  

    
Master Unit

    
Petakan setiap no. unit ke kontraknya (A–D). Pemetaan inilah yang membuat laporan otomatis masuk ke tabel kontrak yang benar saat diinput.

    

      
      
      
      
    

    

  






  

    
Panduan Singkat

    
    
      
  1. Ruang Sinkron (data bersama) — semua perangkat yang membuka aplikasi dengan Ruang yang sama otomatis berbagi data: yang diinput orang satu langsung muncul di perangkat orang lain, tanpa perlu kirim-pesan. Salin tautan ruang di tab 📖 Panduan & Setelan → Ruang Sinkron dan bagikan ke rekan satu tim saja (bukan ke WhatsApp pabrik). Status sinkron tampil di garis di bawah judul: 🟢 tersinkron · 🟡 sedang menyinkronkan · 🔴 luring (data aman di perangkat, otomatis terkirim saat online).
    2. 
      
  2. Siapkan master data — isi 📍 Master Tujuan dan 🚛 Master Unit (pilih kontrak A–D untuk tiap unit). Boleh dilewati: bila master masih kosong, langsung ketik di form input — data baru otomatis tersimpan ke master. Master tersimpan permanen dan bisa diedit (✎) / dihapus (🗑) kapan saja — perubahan ikut tersinkron ke semua perangkat.
    3. 
      
  3. Input harian — di tab 📋 Input Laporan: isi tanggal, ketik/pilih no. unit, pilih kontrak di dropdown (otomatis terisi bila unit sudah dikenal), pilih status (Kirim / Inap / Standby / Storing Perbaikan), dan ketik/pilih tujuan, lalu klik + Tambah Laporan.
    4. 
      
  4. Cek rekap — di tab 📤 Rekap & Kirim WA pilih tanggal; tabel Kontrak A, B, C, D terisi otomatis.
    5. 
      
  5. Kirim WhatsApp — di tab 📤 Rekap & Kirim WA klik 📤 Kirim WA Semua Kontrak: kontrak A, B, C, D digabung menjadi satu pesan dan terkirim sekali. Pesan berformat struk — rata mono bergaris dengan emoji warna status. Nomor tujuan diatur di bawah; bila kosong, Anda tinggal memilih kontak saat WhatsApp terbuka.
    6. 
      
  6. Unduh gambar tabel — di tab 📤 Rekap & Kirim WA klik 🖼️ Unduh Gambar Tabel untuk menyimpan rekap sebagai gambar PNG bergaya tabel Excel (bergaris dan berwarna per kontrak) — praktis dilampirkan ke WhatsApp.
    7. 
      
  7. Rekap ke Excel — di tab 📤 Rekap & Kirim WA klik 📊 Unduh Excel. Hasilnya file .xlsx berisi sheet Rekap (tabel berwarna per kontrak & status, sama seperti rekap yang dikirim ke WhatsApp) dan sheet Semua Data (seluruh riwayat laporan dengan filter siap pakai — tinggal disalin ke file rekap Excel Anda). File bisa dibuka di Excel, WPS Office, atau Google Sheets.
    8. 
      
  8. Kirim Excel ke WhatsApp — klik 📎 Kirim Excel ke WA (rekap harian atau bulanan). Di HP (Android/Chrome): sheet berbagi terbuka — pilih WhatsApp, pilih kontak, dan file Excel langsung terlampir di chat. Di komputer: file Excel otomatis diunduh dan WhatsApp terbuka — kirim pesannya, lalu lampirkan file yang barusan diunduh lewat ikon 📎 (tautan WA tidak bisa membawa file, jadi file dilampirkan manual).
    9. 
      
  9. Laporan bulanan per no. pol — di bagian bawah tab 📤 Rekap & Kirim WA, pilih bulan lalu klik 📊 Unduh Excel Bulanan: file Excel bergaris berisi sheet Rekap per Unit (jumlah Kirim/Inap/Standby/Storing tiap no. pol), sheet Kalender Bulanan (status tiap unit tanggal 1–31: K/I/S/ST, berwarna, akhir pekan disorot), dan sheet Detail Harian (semua laporan bulan itu). Tabel Detail Laporan di layar bisa diedit (✎) / dihapus (🗑) — hapus No. 1 dan nomor berikutnya otomatis menyesuaikan. Bisa juga langsung dikirim ke WhatsApp dengan 📎 Kirim Excel ke WA.
    10. 
      
  10. Kalau popup WA tidak muncul — izinkan popup di browser, atau pakai tombol 📋 Salin Pesan lalu tempel manual ke WhatsApp.
    11. 
    

  

  

    
Nomor WhatsApp Tujuan

    
Format: 62812xxxxxxx (awali 62, tanpa spasi / tanda +). Bila dikosongkan, WhatsApp akan terbuka tanpa nomor dan Anda memilih kontak sendiri.

    

      

    

    

  

  

    
Ruang Sinkron — Data Bersama Antarpengguna

    
Semua perangkat yang membuka aplikasi dengan Ruang yang sama otomatis berbagi data: yang diinput orang satu langsung muncul di perangkat orang lain (tanpa perlu kirim WhatsApp). Laporan, master tujuan, master unit, editan, dan penghapusan semuanya ikut tersinkron.

    

    

      
      
      
      
    

    

      
      
    

    

      
      
    

    

      
      
      

        
        
      

      

      

        📖 Panduan menyiapkan Firebase (± 5 menit, sekali saja)
        
    
          
  1. Buka console.firebase.google.com dengan akun Google, masuk ke proyek laporan-aef1e — cara tercepat: klik tombol 🚀 Buka Console Firebase di atas.
    2. 
          
  2. Menu kiri: Build → Realtime Database → Create Database.
    3. 
          
  3. Pilih lokasi Singapore (asia-southeast1) → Next → pilih Start in test mode → Enable.
    4. 
          
  4. Buka tab Rules, ganti seluruh isinya dengan aturan di bawah ini (agar tidak kedaluwarsa seperti test mode), lalu klik Publish. 

    {
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
    5. 
          
  5. Selesai di console — tidak perlu menyalin apa pun: aplikasi otomatis tersambung sendiri begitu database siap (dicek tiap ± 1 menit). Ingin langsung? Salin Database URL dari bagian atas halaman Realtime Database, tempel di kotak di atas, klik 🔌 Sambungkan. Status di bawah judul berubah 🟢 Tersinkron.
    6. 
        

        
Catatan: aturan di atas memperbolehkan siapa pun yang tahu ID ruang membaca/menulis ruang itu — sama seperti layanan Bawaan. Jangan sebarkan tautan ruang ke luar tim.

      

    

    
Tautan ruang disalin lewat 🔗 Salin Tautan Ruang lalu dibagikan ke rekan satu tim (bukan ke WhatsApp pabrik). Perhatian: siapa pun yang punya tautan/ID ruang dapat melihat dan mengubah data — jangan sebarkan ke luar tim. Bila internet mati, data tetap tersimpan di perangkat dan tersinkron otomatis begitu online kembali.
